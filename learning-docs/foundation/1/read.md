## ⚡ Short Notes

> Core one-liners — know these by heart.

| Concept | What it means |
|---------|--------------|
| 🤖 **APK** | The Android install file — runs directly on a device |
| 📦 **AAB** | Uploaded to Play Store; Google creates device-optimized APKs |
| 🍎 **IPA** | The iOS install package — generated by Xcode |
| 🔏 **Signing** | Every production app **must** be digitally signed — no exceptions |
| 🗝️ **Keystore** | The permanent identity of your Android application |
| 🔢 **versionCode** | Must **always increase** — Play Store uses this to accept updates |
| 🏷️ **versionName** | Human-readable only — visible to users (e.g. "2.3.1") |
| 🚀 **Debug builds** | Use Metro server; JS loaded over HTTP at `localhost:8081` |
| 📦 **Release builds** | JS bundle is embedded inside the APK — no Metro needed |
